Gmail features

JARVIS uses Google's Gmail API to display the number of unread inbox messages. A separate local search helper can display matching message dates, senders and subjects, with links to open messages in Gmail.

Google authorization requests only gmail.readonly. The integration does not request permission to send, delete, archive or modify messages. Read-only access is broader than just an unread counter: Google authorizes reading Gmail data, while the current helpers limit what they retrieve.

This public site provides information only. It does not connect to your Gmail, run the local assistant or accept credentials.

Privacy policy

Effective October 23, 2026. This policy covers the JARVIS Gmail read-only helpers operated by GitHub user Rohitreddyk12345 for personal use.

Information accessed and purpose

With the account owner's consent, the helpers access the unread inbox count and, when the local search feature is used, matching message identifiers, dates, senders and subjects. These support inbox status and local search. The current search helper does not request message bodies, snippets or attachments.

Storage and protection

The OAuth client configuration stays on the Mac. The refresh credential is stored in the local, nonsynchronizing macOS Keychain. Access credentials and retrieved Gmail results are processed in memory. These helpers do not intentionally persist retrieved message metadata or email contents to disk. Optional diagnostic output reports operation stages; optional search status files contain status information rather than message content.

Sharing and use

The Gmail helpers communicate with Google's authorization and Gmail API services over HTTPS. They do not send retrieved Gmail data to this website, GitHub Pages, advertising services or an AI model. Other assistant components and user-directed actions are separate; do not assume that information copied into another component remains local. Google user data is not sold or used for advertising, credit decisions or training generalized AI models by these helpers. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Control and retention

You can stop using the helpers and revoke JARVIS access in your Google Account's third-party connections settings at any time. Local saved credentials remain until removed from macOS Keychain. Revoking access prevents further authorized Gmail retrieval. Opening a message in the Gmail website is governed by Gmail and may mark it read.
